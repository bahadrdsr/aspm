Production.OpenDelivery(ctx, DeliveryConfig) -> (DeliveryAdapter, error)
  Preview(ctx, Action) -> (Preview, error)
  Send(ctx, Action) -> (Delivery, error)
  Status(ctx, nativeIssueKey) -> (StatusLink, error)
DeliveryConfig: Profile, Endpoint, Token, WorkspaceID, Project, IssueType,
Channel, StatusMap, Client, Limits. Action: WorkspaceID, IntentID, ApprovalRef,
FindingID, Title, Body, DeepLink, Fields (string custom fields), Prior *Delivery.
Delivery: WorkspaceID, IntentID, State, RemoteID, RemoteURL, MissingFields,
RetryAfter. Preview exposes MissingFields. StatusLink retains RemoteID,
NativeStatus (status ID), LinkedState and CloseFinding=false.

Production.OpenCollector(ctx, CollectorConfig) -> (Collector, error)
  Collect(ctx, CollectRequest) -> (Collection, error)
CollectorConfig: Profile, Endpoint, FindingsEndpoint, Token, supplied Client,
AWS Credentials provider, Limits. CollectRequest embeds Identity
(WorkspaceID, SourceID, RunID, ScopeID), plus the selected Repository,
Organization, Project, PipelineID, JobID, BuildID, ArtifactName, ArtifactPath,
SubscriptionID, AccountID and Region. Only the selected profile's scope applies.
Collection: Identity, CollectedAt, Complete, Records, Gaps, Continuation,
RetryAfter. Record: Kind, ExternalID, ParentID, NativeRunID, Severity, State,
Location, RawURL, exact Raw bytes, nullable SourceScanAt/SourceUpdatedAt.

Bounds / outcomes
-----------------
Use the injected client/credentials, never ambient credentials or discovery.
Factories do no network I/O. Respect context. Limits.Requests counts all HTTP
attempts, Pages bounds each feed, PageSize bounds requests, Bytes bounds each
response and extracted report. No automatic write/provider retry or redirects.
Validate continuation origin AND selected resource path before sending tokens.
At a page cap preserve Continuation["alerts"] as an unfinished-feed diagnostic;
cross-call resumable checkpoint execution is not certified by this first gate.
Partial/error collection keeps identity and valid collected records, Complete
false and a nonempty Gaps; ErrLimit/ErrScope/ErrAuth/ErrRateLimited/
ErrUnavailable remain explicit. Retry-After becomes a duration, not a sleep.
Complete means this collection scope, NEVER scanner completion or safe absence.
Preserve raw report bytes/URLs. Single-run SARIF 2.1.0 invocation.startTime is a
scan timestamp when present; build/pipeline finish and polling time never are.

The caller must persist an authorized outbox intent before Send and supply its
trusted Prior snapshot. Confirmed/accepted replay returns the same receipt with
no write; uncertain replay returns ErrUncertain with no write until independently
reconciled. 429 is rate-limited, auth/required-field errors failed, lost response
uncertain, denied approval/redirect blocked. No exactly-once delivery claim.

Not covered: durable outbox recovery, Jira edits/transitions, tenant setup,
channel ownership, CODEOWNERS/team inventory, pipeline triggering, GitLab CDN
redirect downloads, all cloud resources/regions, STS/Entra/OAuth bootstrap,
M10 reports/exports, deployed workers or live vendor certification.
Live status for every profile remains UNVERIFIED until separately authorized,
timestamped real-account evidence exists. No catalog promotion from mocks.
