  Production.Plan(ctx, json.RawMessage) (InstallationPlan, error)
  Production.OpenApplication(ctx, ApplicationConfig) (Application, error)
The coder supplies forwarding-only test bindings, untagged for Plan and tagged
integration for the application if needed. Bindings ONLY construct/forward real
components and convert public types/errors. No SQL, business logic, worker loops,
fake HTTP responses, or map/file-backed substitutes belong in them.

ProcessImports is required by intake tests, not by the independent M04 tests.

M04 ROUTES:
POST /api/v1/bootstrap {workspaceName,name,email,password}, with out-of-band
  X-ASPM-Bootstrap-Token from config =>201 {user,workspace}; first role=admin.
  Missing/wrong token =>401; re-enrollment with valid token =>409, including reopen.
POST /api/v1/login {email,password} =>200 {user,workspaces,expiresAt} plus
  aspm_session cookie: HttpOnly,Secure,Path=/,SameSite=Lax|Strict.
GET /api/v1/session =>200 {user,workspaces,expiresAt}; user={id,name,email},
  membership={id,name,role}. JSON never includes passwords/session-token values.
POST /api/v1/logout =>204; revoke server session AND expire cookie.
POST /api/v1/workspaces {name} =>201 {workspace}; admin only, creator joins as admin.
POST /api/v1/users {name,email,password,role} =>201 {user}; admin creates a local
  user in the SELECTED workspace. Roles=admin|analyst|viewer, no implicit memberships.
POST /api/v1/assets =>201 {asset}; GET collection =>200 {items,total,nextCursor};
  GET/PATCH /api/v1/assets/{id} =>200 {asset}; DELETE =>204, then GET =>404.
  Asset={id,workspaceId,name,kind,environment,criticality,tags,ownerId:null|userId}.
  Admin/analyst CRUD; viewer reads only. Owner must belong to selected workspace.
  Fixtures use repository, test/staging, medium/high. Viewer/analyst cannot
  create users/workspaces. No large auth framework or OIDC is required here.

M05 ROUTES:
POST /api/v1/imports uses ONE JSON wrapper, not multipart:
  {apiVersion,assetId,format,report:<exact original bytes as JSON string>,
   sourceId,scanId,scope:{id,revision,branch},sourceScanAt:RFC3339|null,
   collectedAt:RFC3339,sourceStatus:succeeded|failed,scanKind:full|delta,
   completeness:complete|partial|unknown,mapping?:<M07 mapping>}
Source IDs label intake sources, not required native connectors. Admin/analyst
import, viewer cannot; foreign asset =>404. Entire body limit=MaxUploadBytes
(65536 in tests). Bad wrapper =>400, unknown format =>415, oversized =>413.
First upload =>202 {import:{id,runId,state:"queued",...}}. Identical completed
replay may be 200/succeeded or 202/queued, but retains the SAME runId.
GET /api/v1/imports/{id} =>200 {import}; also expose format,sourceId,scanId,scope,
  sourceScanAt,collectedAt,importedAt,reportDigest,observationCount (per-run).
  States=queued|processing|succeeded|failed. Malformed report bytes may queue,
  but terminate failed with failure:{code:"invalid-report",message}, not empty success.
GET /api/v1/imports/{id}/evidence =>200 exact original bytes, authorized only.
  Digest=sha256:<lowercase hex> of decoded report-string bytes, never S3 ETag.
GET /api/v1/work?q=... and GET /api/v1/findings/{id} preserve M01 DTOs.
  q is case-insensitive substring matching title/assetName/ownerName.
GET /api/v1/work/export?format=csv&q=... =>text/csv with the same authorized
  membership and M01 field columns; order/extra columns are unrestricted.
Never replace source scan time with collection/import time. This exercises
the route M01 consumes, not browser behavior or concurrent snapshot exports.
