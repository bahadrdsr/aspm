policy epoch plus bounded title (1..1024 UTF-8 bytes), severity, asset name

no ambient default, wildcard, HTTP downgrade, userinfo, path, query, fragment,

An administrator can select only an exact configured origin. Tenant/admin input
cannot add an origin or override transport, method, headers, TLS, timeout,

This exact list is the generic-webhook SSRF boundary.

{profile:"generic-webhook-v1",name,enabled,webhookUrl,secret}. webhookUrl is a

{"apiVersion":"aspm/webhook/v1","event":"finding.notification",
"deliveryId":"...","workspaceId":"...","findingId":"...",
