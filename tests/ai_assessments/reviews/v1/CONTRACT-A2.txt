A2R1 Actual HTTP/2 native request count
---------------------------------------
The existing one-attempt limit covers requests emitted by the entire selected
transport, including internal HTTP/2 retries, not only entry into an outer
RoundTrip wrapper. A single job/DB attempt/quota charge must not produce a
second actual POST request stream after REFUSED_STREAM.

An owned certificate/hostname-verified TLS fixture negotiates h2 and sends real
bounded HTTP/2 frames. It receives a complete native POST and exact JSON context,
then emits RST_STREAM REFUSED_STREAM while leaving the connection reusable.
A second request, if emitted, is counted independently by connection/stream ID
and gets a bounded native response so the test need not wait through retries.
The test counts actual decoded HEADERS/POST streams and received body bytes.

job cannot release concurrency while its owner's local provider I/O is still
active. A terminal public state and resource termination are different facts.
Admission remains reserved until owner I/O termination is acknowledged or a
conservative bounded execution deadline settles the resource lifetime.

Use actual owned PG/API-produced previews/jobs and two independent workers.
The normal TLS native server holds its response and HONORS request cancellation.
Its ready event follows real protocol/body/context and committed marker checks.
A transparent net.Conn observer delegates all real I/O and records local socket
open/Close lifetime; it never manufactures an HTTP response or delays Close.
Count actual POSTs and maximum simultaneously live local provider sockets.
Do not infer that remote model compute has stopped from a client disconnect.

A read-only pgx query tracer pauses the first worker's next real authority SELECT
before execution while its response is held. It observes/coordinates scheduling
only, respects context cancellation, performs no SQL business write and changes
no pool/timeout/budget or production cancellation behavior.

first local provider socket is demonstrably still live.
Worker two must not start the second native request in that interval, even
though request-window capacity remains available.
