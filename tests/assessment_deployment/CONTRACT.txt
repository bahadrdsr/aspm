AD3 - Declared defaults and a finite validation table
----------------------------------------------------
Actual values.yaml declares the chosen assessment defaults above.
assessment.enabled must be a boolean. scope must be a string, valid UTF-8,
nonblank when enabled, with no surrounding whitespace/control and at most
128 UTF-8 bytes. A valid nonempty scope remains usable for core-only setup;
malformed supplied scope rejects even while disabled. A Unicode/slash positive
and exact 128-byte positive prevent an invented DNS/ASCII-only scope rule.

Each rejection identifies its precise values path, not an unrelated validation
error. The finite cases cover malformed assessment mapping, flag string/number,
required scope, padded/control/typed/129-byte Unicode scope, blank/numeric
duration values, string/fractional concurrency, zero request-window capacity,
oversize response cap, and both partial integrationKeySecret selectors.
Supplied invalid values must not silently become false or restore defaults.
Existing complete-key and absent-key behavior must remain separate.
The runtime remains authoritative for complete duration grammar, cross-field
constraints and execution-time bounded validation; this is not another runtime
policy implementation or a huge Cartesian value matrix.
