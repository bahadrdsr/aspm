SOURCES UI A1 - ONE RETRY-AFTER REGEX ESCAPE CORRECTION
====================================================

Confirmed original-author defect
--------------------------------
The coder blocker, actual spec, production collection detail and archived
trace were independently inspected. The trace contains the valid literal UI:
  Retry-After: 7 seconds. Retryable: false. No automatic retries.

An independent original SU4 run reproduced the line-142 mismatch against
that same valid text. The old regex incorrectly required a literal backslash
after its optional colon rather than optional whitespace before the value.
This is a test-pattern escape defect, not a production formatting requirement.
No backslash-display workaround is introduced.

Only one byte changes
--------------------
The old regex:
  /retry.after\s*:?\\s*7\s*(?:s\b|seconds?)/i
becomes:
  /retry.after\s*:?\s*7\s*(?:s\b|seconds?)/i

Exactly one backslash is removed. The label, numeric 7, whitespace handling
elsewhere, unit alternatives, case-insensitivity and original assertion
remain. Every other byte in the complete spec is identical, including all
collection/raw-evidence/partial/no-retry/role/epoch assertions and budgets.

omitted colon, singular unit, short s unit and case-insensitivity.

pattern outcomes match the expected classification.

deliberately invalid backslash used to demonstrate the old bug. The old regex
does not permit that space after its colon; only that diagnostic positive
control was corrected. No second spec/source change occurred. This diagnostic
note and all exact inputs/results are retained in pattern-calibration.json.
